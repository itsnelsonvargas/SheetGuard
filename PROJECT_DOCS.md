# SheetGuard Project Documentation

## Overview
SheetGuard is a professional desktop application designed for cleaning and validating Excel and CSV spreadsheets. It leverages a JSON-based rule engine, allowing users to define complex cleaning and validation logic without writing code. The application is built with Python, using **PySide6** for the GUI and **pandas** for high-performance data processing.

## Key Features
- **Data Import**: Supports `.xlsx`, `.xls`, and `.csv` files.
- **Rule Engine**: Configurable JSON rule sets for cleaning, validation, and duplicate detection.
- **Cleaning Operations**:
    - `trim`: Remove leading/trailing whitespace.
    - `collapse_spaces`: Replace multiple spaces with a single space.
    - `uppercase`/`lowercase`/`title`: Change text casing.
    - `remove_special`: Strip non-alphanumeric characters (preserving common symbols like `-._@`).
    - `normalize_date`: Standardize dates to `YYYY-MM-DD`.
    - `numeric_cleanup`: Parse and sanitize numeric strings.
- **Validation Constraints**:
    - `required`: Ensures fields are not empty.
    - `allowed_values`: Restricts values to a predefined list.
    - `regex`: Validates against custom regular expressions.
    - `min_length`/`max_length`: Enforces string length limits.
    - `min_value`/`max_value`: Enforces numeric ranges.
    - `date_format`: Validates date strings against a specific format.
    - `lookup`: Checks values against external CSV/Excel reference files (supports fuzzy matching).
- **Duplicate Detection**: Identifies duplicate rows based on composite keys (multiple columns).
- **Interactive GUI**:
    - Drag-and-drop file upload.
    - **Rule library management**:
        - Import/Export/Clone rules.
        - Delete rules from the library.
        - Switch library folders to use different collections of rules.
    - **Visual rule builder**: Interactive editor for `RuleSet` objects, with automatic library refresh on save.
    - Result preview with summary cards and searchable tables.
    - Dark/Light theme support.
- **Reporting**: Generates multi-sheet Excel workbooks with:
    - `CLEANED_DATA`: Color-coded data (Green: corrected, Red: error, Yellow: warning).
    - `VALIDATION_ERRORS`: Detailed list of all findings.
    - `DUPLICATES`: Grouped duplicate rows.
    - `SUMMARY`: High-level metrics.

## Technical Architecture

### Core Components (`sheetguard/core/`)
- **`cleaner.py`**: Implements vectorized cleaning logic using pandas.
- **`validator.py`**: Executes validation rules and handles external lookups with fuzzy matching via `rapidfuzz`.
- **`duplicate_checker.py`**: Identifies row groups sharing identical values across specified columns.
- **`rule_engine.py`**: Handles loading, saving, and validating JSON rule configurations.
- **`exporter.py`**: Uses `openpyxl` to generate formatted Excel reports.

### GUI Layer (`sheetguard/gui/`)
- **`main_window.py`**: The primary entry point for the UI, managing the sidebar, navigation, and background processing threads.
- **`rule_builder.py`**: A panel for interactive editing of `RuleSet` objects.
- **`results_view.py`**: Displays summary cards and data tables for the processed results.
- **`widgets/`**: Reusable UI components like `FileDropZone`, `DataTable`, and `SummaryCards`.

### Services (`sheetguard/services/`)
- **`pipeline.py`**: Orchestrates the full "Load -> Clean -> Validate -> Detect Duplicates" flow.
- **`file_loader.py`**: Standardizes the ingestion of different file formats into pandas DataFrames.
- **`rule_service.py`**: Manages the local rule library and file-system interactions for rules.

### Models (`sheetguard/models/`)
- **`rules.py`**: Dataclasses for `RuleSet`, `ColumnRule`, `DuplicateRule`, and `LookupSource`.
- **`results.py`**: Structures for `ProcessingResult`, `ValidationIssue`, and `DuplicateGroup`.

## Configuration (Rule Files)
Rules are stored in JSON files. A typical rule set includes:
- `rule_name` and `version`.
- `columns`: A list of `ColumnRule` objects mapping spreadsheet columns to cleaning and validation logic.
- `duplicate_rules`: Definitions of what constitutes a duplicate.
- `lookups`: Paths to external reference files.

## Development & Build
- **Dependencies**: Listed in `requirements.txt` (PySide6, pandas, openpyxl, rapidfuzz).
